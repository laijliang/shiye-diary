# 拾页日记 · 前端 MVP（UI v2）

《拾页日记》AI 叙事陪伴日记的移动端 Web 高保真实现。**v2 按「旧书店的一盏灯」重做了整套视觉与交互**：牛皮纸底、墨色字、一种主色；页面用灰泥纸纹、卡片与浮层用亚麻布纹、封面用皮革；去掉噪点、双层渐变、整屏玻璃和彩带；开场是真正的手势——推开书封。

无需构建工具、无外部依赖，打开静态服务器即可运行。

---

## 快速开始

```bash
cd web
python serve.py
# 打开 http://127.0.0.1:4173/
# 演示数据：http://127.0.0.1:4173/?demo=1
```

`serve.py` 关闭缓存，改完 CSS/JS 刷新即可。设计基准 **390 × 844**，兼容 360–430px；桌面端居中为 430px 的书页列。

> 不要直接双击 `index.html`。本地服务器能保证 localStorage 的 origin 稳定，也方便手机同局域网访问。

手机调试：同一 Wi-Fi 下访问 `http://电脑局域网IP:4173/`。真机才能验证按压反馈、软键盘、安全区和滚动惯性。

## 演示路线

1. 打开 → **书封开场**：向左拖会先卷起纸边、再把整页翻过去；拖过 35% 或快速一甩即打开，轻点也能打开。
2. 进入对话：空态是阿页和三枚建议胶囊；点一下只是填进输入框，不会替你发送。
3. 输入一句话 → 发送 → 阿页按人设回复；顶部状态会短暂变成对应的情绪页灵。
4. 对阿页说「你能做什么」→ 它会说明能力；说「帮我整理今天的日记」/「把这一页的情绪改成开心」/「摘要改成……」→ 它会整理或改好今天这一页，并在聊天里放一张可翻开的日记卡；这些指令不会被写进日记素材。
5. **按住麦克风** → 使用浏览器语音识别（首次会要麦克风权限），说完松开上屏；按住时上滑 56px 取消；不支持的浏览器会明确提示回退演示文本。
6. **长按任意一句话 500ms** → 夹书签 / 复制；书签会同步到当天日记与日历小旗。
7. 日历 → 顶部是「11 月」大字与情绪色格子；点有情绪的日期 → 日记详情。
8. 日历 → **本月书页**横向滑动（原生吸附，跟手、可中途接住）；页码点 / 计数同步。
9. 日历 →「全部情绪」→ 多选筛选；非命中日期保留结构、命中情绪高亮。
10. 我的 → 改「每日成稿时间」/「日记风格」；开关和设置持久化。页面底部只保留真实可用的设置。
11. 我的 →「重演今日成稿」→ 纸页逐行写完 → 变成日记卡 → 无彩带、无纸屑。
12. 我的 →「重看开场」可重播书封。

对话页顶部「阿页」那一行可点开人设说明。

## 设计系统 v2

### 一句话

一间永远停在黄昏的旧书店：**纸是底，墨是字，树皮棕是结构，叶绿只表示「活着」**。情绪色是数据，不是装饰。

### 材料与层级

- **一种纸**：`--paper: #F5EFE3`；正文卡片 `--card: #FFFDF8`。页面用 `assets/paper-plaster.jpg` 以 multiply 压进纸色，顶部只有一条极淡的提亮渐变。
- **纸纹只叠一层**：页面 = 灰泥纸纹；卡片 / 浮层 / 输入坞 = 亚麻布纹；封面 = 皮革。三处各只有一层材质，不叠噪点、不叠第二层纹理。
- **两级阴影**：`--shadow-1`（卡片）、`--shadow-2`（浮层）。抬起的表面用阴影和背景差分离，不用 1px 实线边框。
- **不再叠玻璃**：只有底部导航一条 `backdrop-filter`（贴底 chrome），其余表面都是实色纸。大面积磨砂会让手机掉帧，也会让层级糊成一片。
- **分隔线只做「同一张卡内部的名单」**：`--hairline` 只出现在列表行之间和内容区段之间。

### 颜色语义（最重要的约束）

- **树皮棕 = 结构 / 主按钮 / 选中**：`--bark-800`。
- **叶绿 = 活着的状态**：麦克风、聆听波形、在线点、开关、空态插画。**不做按钮底色**。
- **黄昏 = 书签 / 重要片段**：`--dusk`，只做标记，不做主色。
- **情绪色 = 数据**：只出现在日历格、情绪胶囊、日记卡书脊、月度情绪条、详情页印章。
- 破坏性操作使用陶土色 `--danger: #B5563F`，不用纯红。

| 情绪 | 主色 | 日历格 | 胶囊底 | 文字 |
|---|---|---|---|---|
| 开心 | `#E39A56` | `#F6D9BB` | `#FBEDDD` | `#7C4718` |
| 平静 | `#D9B96A` | `#F1E3BC` | `#F8F0D9` | `#6A571F` |
| 低落 | `#8AA2B8` | `#D3DFE8` | `#E9F0F4` | `#3D4F5E` |
| 焦虑 | `#A992CC` | `#DED3EE` | `#EFE9F7` | `#513D75` |
| 复杂 | 双色 | 135° 硬切 | `#F2E6DA` | `#4A382A` |

混合情绪用双色硬切，不用渐变；数据结构仍是 `entry.mix = ["joy","low"]`。

### 字体

- **页面标题 / UI**：系统无衬线（`-apple-system / PingFang SC / HarmonyOS Sans SC / Noto Sans SC`）。
- **日记正文 / 阿页说的话 / 日期大字**：中文衬线（`Noto Serif SC / Songti SC`）。
- **用户说的话**：无衬线。阿页像书页，你说的像便签。
- 字号下限：正文 15px，辅助 11px，**输入框 16px**（低于 16px iOS 会在聚焦时放大页面）。
- 大字号收紧字距（`letter-spacing: -.01em`），小字不做负字距。

### 角色

- **阿页**：奶油纸页灵位图（`assets/ayeh-*.webp`，640×800 透明、底部对齐、带统一地面柔影）——右上角折角、黄昏书签腰带 + 燕尾、头顶嫩芽、晚霞红晕。5 种表情：听 / 应答 / 思考 / 困 / 高兴；28px 以下自动换成 `*-face.webp` 头像裁切。生成需求见项目根目录 `ayeh-mascot-brief.md`。
- **情绪页灵**：小橙（圆润三角 + 星）、小米（叠起的便签）、小雨（水滴 + 泪）、小线（毛躁的圆 + 锯齿嘴）、小花（双色云 + 不对称眼）。
- 剪影规则：**涂成纯黑，在 16px 下仍可区分**；18px 以上画脸，16px 以下只保留轮廓和色块。

### 形状

卡片 18px、页面卡片 22px、浮层 26px、气泡 18px（单角 6px）、胶囊 999px、日历格 12px。圆角收敛到 22px 以内，不再每张卡都 30px。

### 动效

- 曲线：`--ease-out: cubic-bezier(.23,1,.32,1)`；`--ease-in-out: cubic-bezier(.77,0,.175,1)`；抽屉 `--ease-drawer: cubic-bezier(.32,.72,0,1)`。**不使用内置 ease-in。**
- 时长：按压 120ms；页面 220ms；浮层 320ms；书封 640ms。
- 所有可点元素 `:active { transform: scale(.97) }`（大按钮 .97，小图标 .92），100–160ms。
- 页面入场只做**一次**（`.page-body` 淡入 + 6px 上浮），不再让每个子元素排队入场。
- 新消息 220ms 淡入上浮；打字点只改透明度，不跳。
- 导航选中指示条 240ms `ease-out` 滑动；切页内容按 tab 方向 14px 进入。
- 月份切换按方向从 ±12px 淡入。
- `prefers-reduced-motion: reduce` 下保留透明度变化，去掉位移与旋转。

### 手势

- **书封**：封面先画进 canvas，再按 2px 竖列做柱面卷曲——拖动先卷起纸边（主页面滞后），再整页翻过去；松手按位移（>35%）或速度（< -0.55 px/ms）决定翻开或回弹；可在中途抓住，轻点 / Enter 也能开。
- **浮层**：从把手往下拖 1:1 跟随，超过 60px 后阻尼；松手按位移（>26% 高度）或速度（>0.5 px/ms）关闭；遮罩透明度跟着拖拽实时变化；关闭动画从当前位置继续，不跳。
- **本月书页**：原生横向 `scroll-snap`，滚动惯性由浏览器负责；`scroll-padding-inline` 保证每张卡停在与页面同一条 20px 边线上；左右箭头键也能翻页。
- 所有拖拽中途都不锁输入。

### 移动端基线

- `-webkit-tap-highlight-color: transparent`；控件 `touch-action: manipulation`；`overscroll-behavior: none`。
- `100dvh` + `viewport-fit=cover` + `env(safe-area-inset-*)`。
- `theme-color` 与纸色一致；`interactive-widget=resizes-content`。
- hover 样式全部包在 `@media (hover:hover) and (pointer:fine)` 内，触屏不会留下粘住的悬停态。

## 已实现

- 材质：页面灰泥纸纹、卡片与浮层亚麻布纹、封面皮革；全部为本地 JPEG，纹理只叠一层。
- 底部导航：只建一条，选中指示条随 tab 滑动（240ms）；再点当前 tab，对话回到最新、其他页回到顶部；详情页自动收起。
- 书封开场：拖拽 / 轻点 / 键盘 Enter 打开；桌面端同样居中。
- 三个主页面 + 日记详情：树洞对话 / 情绪日历 / 我的；旧欢迎页移除，开场替代它。
- 对话：阿页状态行、今日收下几段、空态建议、文字发送、按住说话（浏览器语音识别 / 演示回退）、上滑取消、打字态、情绪镜像、长按夹书签 / 复制、新消息入场；可以直接用自然语言让阿页整理/修改今天这一页（能力问答、改摘要/正文/情绪），改完在聊天里出现可翻开的日记卡，指令不计入日记素材。
- 日历：月份大字与方向切换、情绪格 + 情绪页灵、今日描边、重要小旗、月度情绪条、横向书页（原生吸附 / 页码点 / 键盘）、情绪多选筛选、空月份。
- 详情：第一人称日记、情绪印章、原始片段折叠、收藏、系统分享（不支持时复制）、重要片段计数、前后页。
- 我的：人设说明、成稿时间、日记风格、自动成稿、语音 / 播报 / 提醒、模型配置、导出、清空二次确认、演示成稿、重看开场。
- 本地持久化：设置、按日期归档的对话、书签、收藏、筛选、生成的日记。
- 无外部依赖；情绪页灵与图标为内联 SVG，阿页为本地 WebP 位图。
- PWA：`manifest.json` + 192/512/180 图标，可添加到主屏幕；没有 Service Worker，首次打开仍需联网。

## 接真实后端的位置

当前默认是纯前端演示；聊天可接真实模型，语音使用浏览器识别：

| 位置 | 现状 | 接入方式 |
|---|---|---|
| `js/data.js → detectEmotion()` | 关键词规则 | 换成情绪分类 API 返回值 |
| `js/data.js → AI_REPLIES` | 没有模型配置时的本地回复 | 换成自有 `/chat` 代理；保持阿页 system prompt + JSON 动作 schema |
| `js/data.js → VOICE_SINGLE / VOICE_PAIRS` | 浏览器语音识别不可用时的演示文本 | 真实识别已走 Web Speech API；自有 ASR 用 MediaRecorder + 流式结果 |
| `js/data.js → buildEntryFromMessages()` | 模板拼接 | 换成 `/generate-diary` 的结构化输出 |
| `js/app.js → ensureTodayEntry()` | 到点 / 聊天指令触发 | 换成服务端 22:30 定时任务 + 推送 |

日记数据结构不变：

```js
{
  date: "2026-11-20",
  emotion: "calm",             // joy | calm | low | anxious | mixed
  mix: ["joy", "low"],         // 仅 mixed
  summary: "一句话摘要",
  body: "第一人称日记正文",
  fragments: [{ text, time, important }],
  generatedAt: "22:30",
  favorite: false
}
```

前端只消费这个结构；AI 层 Prompt 负责「去口语化、第一人称、保留核心事件与情绪」。

## MVP 边界与已知说明

- 默认 AI 回复是**本地演示**；在「我的 → 模型」配置后会请求该地址，并把对话和今日日记上下文发过去。语音识别由**浏览器**提供（浏览器可能将它交给自己的语音服务）；本应用不保存录音。
- 自动成稿不是真正的定时任务，通过「重演今日成稿」触发；真实版本需要服务端调度。
- 分享已接入系统分享（Web Share），不支持时回退复制；长图导出仍未开放。
- 可添加到主屏幕（PWA），但没有 Service Worker，离线打开仍需网络。
- 自定义人设、多端同步、向量记忆未实现。
- 数据只存在当前浏览器的 `localStorage`，清空浏览器数据即丢失。
- `?demo=1` 的种子日记只在**首次运行**（localStorage 为空）时生成；之后再进演示页会沿用已有数据。
- 字体使用系统字体栈；Android 若无中文衬线字体会回退，观感略有差异。
